# Setup Guide for running the Expo Application + GDCM library


1.  Install dependencies using
```bash
npm install
```

2. Download and extract the .zip file from this link

   Google Drive Link: https://drive.google.com/file/d/10dyLmDsrWWkVU64idNPkZHNWvUYDdOCo/view?usp=sharing

2. Navigate to modules --> native-dicom --> android

3. Paste the header files inside the include folder

4. Paste the library static files inside arm64-v8 and x86_64 to their designated folders

5. Build and run using Android Studio with a running emulator using this command npx expo run:android
```bash
  npx expo run:android
```
